# Tic Tac Toe

A browser version of Tic Tac Toe game built with HTML, CSS and JavaScript as part of The Odin Project curriculum. The purpose of this project is to create game functionally and logic using factory functions, the module pattern, IIFE's and encapsulation to reduce the use of global variables.

Live preview is [here](https://cansubaydar.github.io/tic-tac-toe/)

## Features

- Modular JavaScript architecture (separation of game logic and UI)
- Form-based player setup (player name + mark selection)
- Deterministic turn logic (X always starts the game)
- Dynamic status updates (turn, win, draw)
- Restart functionality at any time
- Additionally, play against an AI opponent
  The AI is implemented using a depth-limited Minimax algorithm, ensuring the game is challenging but not unbeatable, applying decision-making logic and recursive evaluation to determine optimal moves within a specific search depth.

## Built With

- JavaScript (ES6+)
- HTML5 & CSS3
